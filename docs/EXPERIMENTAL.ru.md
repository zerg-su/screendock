# ScreenDock Experimental 0.1.0

Список открытых окон с поиском по названию документа или приложения.
Включает свёрнутые окна, скрытые приложения и окна других рабочих столов.

## Установка

1. Распакуйте архив.
2. Перенесите **ScreenDock Experimental.app** в **Программы**.
3. Запустите приложение.
4. Разрешите ему **Универсальный доступ** в настройках macOS:
   **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.
   Включите именно **ScreenDock Experimental**.
5. Вернитесь в приложение и нажмите **Обновить**.

Если macOS заблокирует запуск, после копирования в «Программы» выполните
в Терминале одну команду, затем запустите приложение снова:

```fish
xattr -dr com.apple.quarantine '/Applications/ScreenDock Experimental.app'
```

Сборка экспериментальная. У неё нет Developer ID и нотариального заверения Apple.
Она работает на Intel и Apple Silicon с macOS 13 или новее.

## Использование

- Нажмите значок окон в строке меню сверху или **Control + Option + Пробел**.
- Введите часть названия документа или приложения.
- Выберите окно стрелками и нажмите **Enter**, либо дважды нажмите на строку.
- Свёрнутое окно развернётся. Скрытое приложение появится снова.
- **Esc** закрывает список. Приложение продолжает работать.
- Для выхода нажмите **Выход** в списке или правой кнопкой на значок в строке меню.

Запись экрана не требуется. Названия окон не отправляются в сеть и не сохраняются.
Обычный ScreenDock можно оставить установленным: это отдельное приложение.

## Ограничения

- Вкладки внутри браузера не перечисляются отдельно. Видны окна браузера.
- Нет превью окон и автоматической раскладки окон по экрану.
- Некоторые приложения не отдают названия или окна через «Универсальный доступ».
- macOS может не отдать полноэкранное окно другого рабочего стола при первом
  запуске ScreenDock. Один раз покажите это приложение и обновите список.
- Если приложение зависло, список покажет предупреждение о неполных результатах.
- macOS управляет переключением рабочих столов. Если конкретное приложение
  не даёт открыть окно, ScreenDock покажет ошибку.
- Если сочетание клавиш занято другой программой, используйте значок в строке меню.

Для удаления выйдите из приложения и перенесите его из «Программ» в Корзину.
